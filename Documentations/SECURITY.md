# Security Policy

## Reporting Security Vulnerabilities

We take the security of FocusFlow seriously. If you believe you have found a security vulnerability in FocusFlow, please report it to us as soon as possible.

Please **do not** publicly disclose the vulnerability until we have had a chance to address it.

To report a security vulnerability, please email us at: security@focusflow.app

Please include as much of the following information as possible to help us better understand and resolve the issue:

- Type of issue (e.g., XSS, CSRF, etc.)
- Full paths of source file(s) related to the manifestation of the issue
- Any special configuration required to reproduce the issue
- Step-by-step instructions to reproduce the issue
- Proof-of-concept or exploit code (if possible)
- Impact of the issue, including how an attacker might exploit it

This information will help us triage your report more quickly.

## Preferred Languages

We prefer all communications to be in English.

## Response Timeline

We aim to respond to security reports within:

- 48 hours for initial acknowledgment
- 5 business days for assessment and planning
- 30 days for resolution of confirmed vulnerabilities

We will keep you informed of our progress throughout the process.

## Security Updates

When we release security updates, we will:

- Clearly label them as security releases in our changelog
- Provide detailed descriptions of what was fixed
- Recommend that all users update as soon as possible

## Scope

This security policy applies to all code in the FocusFlow repository.

## Bounty Program

At this time, we do not offer a bug bounty program for security vulnerabilities.

## Acknowledgements

Security researchers who responsibly disclose vulnerabilities will be acknowledged in our release notes and on our CONTRIBUTORS.md page, unless they wish to remain anonymous.
